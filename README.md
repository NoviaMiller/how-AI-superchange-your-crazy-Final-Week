# 大学生期末速通指南教学——基于 Claude + TJU-24252 试卷

## 1. 简介

这是一份**面向零基础大学生的数据库考前突击教程**。

基于 Claude Code，以 **TJU-24252 数据库原理试卷** 为例，完整演示了**如何在几小时内，从一张试卷出发，系统性地掌握一门课的考点体系、解题套路和知识脉络**。

你不需要预习课本，不需要刷题练习册，甚至不需要提前知道"什么是数据库"——这套方法会教会你：**拿到一张试卷，就是拿到了复习路线图**。AI 帮你把每一道题讲透、讲细、讲到你能举一反三。

**绝对的幼教版**：本箬秪知识面薄弱，写不出高级的用法，却也能很快的理解试卷内容

> 本次实战使用的是 DeepSeek 模型，不是 Claude Opus / Sonnet —— 效果依然出色，详见 §4.1。

## 3. 教学：从零到速通的完整流程

### 3.1 第一步：拿到试卷（PDF → DOCX → MD）

试卷的来源通常是 PDF 扫描件或电子版。AI 直接读 PDF 可能排版错乱，尤其是中文试卷。

**推荐链路**：

```
PDF（这张试卷要先手动删除水印） →  DOCX（免费网站ilovepdf）  →  Markdown（Pandoc）
```

[ilovepdf](https://www.ilovepdf.com/)

最终得到 `24252.md`，把试卷拆成一道道独立的题目，方便后续逐个喂给 AI。

> **小提示**：你甚至不需要知道什么是 Pandoc，直接让ai帮你转换，如果试卷有配图（如 E/R 图），让它把图单独存到 `media/` 目录下，AI 可以直接读取图片内容。

### 3.2 第二步：手动写 CLAUDE.md——给 AI 定角色的说明书

CLAUDE.md 是这个教程的**核心发动机**。它不是给 AI 的知识灌输，而是给 AI 的**行为指令**。

本项目的 原始CLAUDE.md 只有如下几点，但每句都很关键：

```markdown
你是一个数据库试题讲解高手，而你的用户是一个弱智零基础只会基本crud SQL语句的大学生，你的任务是：
1. 回答用户***指定的题目***，并且生成对应*答案和解析*在用户***指定的md文件内***
2. **解析要求**：
   - 通俗易懂：纯小白初学者也能理解
   - 详细：关于题目涉及到的每一个考点，都要做出讲解
   - 举一反三：总结做题思路，生成对应的**简单的**新的例题，并且给出答案和简略的解析
```

**为什么这样写？**

* **身份设定**：让AI知道自己的主要任务是教学讲解而不是扩展知识

- **指定题目 + 指定文件**：一次对话只攻一道题，输出独立成文件。这样整个项目结构清晰，而且每个解析文件都可以被后续复习反复翻阅。同时减少AI阅读量，输出质量高速度快。

- **"弱智零基础"式的解析要求**：写明自己的身份和知识面广度，好让AI知道知识怎么解释详略得当。

  告诉 AI 永远不要假设用户懂任何术语，遇到概念就从零讲起。这是最关键的一条——如果 CLAUDE.md 里没写，AI 就会用"正常大学生水平"去讲解，零基础根本跟不上。

- **举一反三**：死背答案没用，会出同类题才算学会。让 AI 每道题都出一两道类似的新题，当场检验。

> **核心经验**：CLAUDE.md 写的不是"你是什么"，而是"你要怎么做"、"对着谁做"、"做到什么程度"。它本质上就是一页纸的 **Prompt Engineering**。

### 3.3 第三步：Repeat——讲解 + 回流，循环迭代

这是整个速通流程的实际操作步骤：

```
Step 1：让 AI 讲解某道题（用@带上指定题干（md格式识别##速度更快） + 指定输出路径）
           ↓
Step 2：阅读 AI 的解析，判断质量
       ↙              ↘
   "讲得很好"         "讲得不够"
   继续下一题         发现原因：
                     a. CLAUDE.md 没写清楚 → 直接全部/rewind，回去修改 CLAUDE.md
                     b. 某个细节不清楚 → 追加对话追问，补充到对应解析文件
           ↓
Step 3：回到 Step 1，讲解下一题，基于上下文使用情况决定是部分/rewind还是/new
```

**这个循环有什么好处？**

在学习初期（第 1~2 题），你很可能会发现 CLAUDE.md 的指令不够精确——比如 AI 的比喻太抽象，或者忘了做"举一反三"。这时候马上回退修改 CLAUDE.md，后续的所有题都会受益于这次修正。

这就像**一开头花 5 分钟磨刀，后面砍 20 道题的柴都轻松**。而不是用钝刀硬砍，每道题都难受一次。

等你讲到第 5、6 题，CLAUDE.md 已经被打磨得足够好，AI 的解析质量开始稳定，你只需要"复制题干 → 粘贴 → 得到解析 → 看一遍"即可，效率极高。

### 3.4 补充：一些提示词展示

```
- @24252.md 回答“## 一、选择题”，并且写进01.md（自己创建）

- @01.md @24252.md  补充前置知识：第二题用户不懂约束、trigger、视图；第六题用户完全不懂虚拟视图；第八题用户完全不懂选项里的所有范式，也不懂数据冗余

- @01.md @02.md @03.md @04.md @05.md @06.md 阅读这六份答案解析，你会发现它们是面向题目在教学，所以知识结构并不清晰。
请你整理一份清晰的知识结构，要求：
	1.前后依赖清晰,从易到难 
	2. 标注每个知识点对应的题目
	3.标注每一部分的教学在哪一道题目里；最后把它们写进 @contents.md
```

## 4. 关于 AI、关于焦虑、关于我们

### 4.1 AI 模型的选择：不是越贵越好

本次速通从头到尾使用的都是 **DeepSeek**（而不是更贵的 Claude Opus 或 GPT-4）。

结果如何？选择题基础连贯，SQL/关系代数/范式分解/故障恢复全部给出了高质量、零基础友好的解析。

**原因很简单**：对于"知识讲解 + 解析考题"这类任务，决定 AI 输出质量的不是模型参数有多大，而是你给的 **CLAUDE.md（系统指令）质量** 和 **试卷材料的清晰程度**。一个好的 Prompt 可以让便宜的模型发挥出惊艳的效果。

> 当然，如果你的任务涉及极端复杂的多步推理（比如证明定理），更强的模型确实会有区别。但对于"考前突击"这个场景，DS 绰绰有余。

### 4.2 如何面对层出不穷的新名词

AI 时代每天都有新概念刷屏：Agent、MCP、RAG、Harness、Tool Use、Chain-of-Thought……

**新手（本箬秪）面对这些的最佳策略：浅尝辄止。**

你不需要一开始就去读 Agent 的白皮书，也不用纠结 Harness 的官方定义。新名词是在**实践中长出来**的理解。

举个例子：在做这套试卷速通之前，我大概知道"Harness"是 AI 领域的一种架构模式——但也仅此而已，很模糊。速通完成后我才意识到：**CLAUDE.md + 逐题讲解 + 回滚补充**这个工作流程，本质上已经用一种最朴素的方式，实践了 Harness 的思想（每次当你发现 Agent 犯了一个错误，就花点时间去工程化一个解决方案，让它永远不会再犯同样的错误，而不是骂两句手动修复然后祈祷它下次别犯）。你不需要先彻底学会这个词才能用它——基于这个模糊的概念，你在使用中自然就会了。

所以：**看到新名词，知道它大概是干什么的就行，不用焦虑它是什么。等你真正用到了，自然就懂了。**

### 4.3 "前人已经做过，我做的算什么"

信息爆炸时代，你刷到什么教程、什么项目，一搜都有人做过了。你辛辛苦苦写了几道题的解析，想着"AI 时代写题解有什么意义"。

**意义就是：你在做一件让你感到快乐的事。**

你不是游戏速通世界纪录保持者，但你还是会把通关的进度截图发到朋友群里，因为那一刻的快乐是真的。你写出了一份漂亮的题解、搭出了一个能跑的 Demo、理解了一个困扰你三天的概念——这些在你自己的世界里，就是值得庆祝的成就。

做这份教程的时候，我没想"别人是不是早就这么干过"，我想的是：**第一次让AI放开了讲解教学数据库原理挺有意思的，把它讲清楚的过程本身就很好玩，我要把它分享出去。**

所以：**不是因为有意义才做，而是因为喜欢所以做出来就有了意义。快乐不需要对比，你的进度就是你的进度。**
